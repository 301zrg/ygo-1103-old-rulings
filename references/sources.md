# 来源说明

## yugioh-wiki（遊戯王カードWiki）

- 卡片页名：`《日本語カード名》`；术语页没有《》（如「ライトロード」「エラッタ」）。
- 历史版本列表：`https://yugioh-wiki.net/index.php?cmd=backup&page=<EUC-JP 编码的页名>`，每行 `N (YYYY/MM/DD HH:MM:SS)`。
- 某一版：在上面后面加 `&age=N`。引用一律用这种链接。
- 当前页面（不带 cmd=backup）只用于勘误列表这类“当前汇总”，不用于旧裁定。
- 问答格式：`Ｑ：…` 一行、`Ａ：…(YY/MM/DD)` 一行；日期有时写成 `（11/2/5）` 这样的全角括号或缺零。
- 页面说明（不在问答里的正文）也可以作依据，但没有裁定日期，引用时注明“页面说明”。
- 已知局限：
  - 术语页（戦闘破壊、ダメージステップ等）历史只从 2014～2017 年开始。
  - 不少卡 2011 年没有存档，首个存档是 2012 年以后；看裁定日期判断。
  - 后来的编辑可能改写旧问答但保留原日期，必须核对到具体那一版。
- 勘误列表：「エラッタ」页（<https://yugioh-wiki.net/index.php?%A5%A8%A5%E9%A5%C3%A5%BF>）列出被勘误的卡和各次批量勘误，其中 2014-07-10 的 279 张勘误把“エンドフェイズ時まで”统一改为“ターン終了時まで”（此前这类效果在结束阶段单独失效）。

## 寒波亭（note）

- 《1103環境　主要カード　裁定まとめ》：<https://note.com/sabae5280/n/n95ba4b085cf6>
- 开头说明：「基本的に全てマスタールール2における該当時期・1103環境に一番近いタイミングの当時裁定」，没有逐条日期。
- 条目以卡名单独成行作为标题（卡名与卡库日文名一致，偶有空格差异，如「ライトロード・モンク　エイリン」用全角空格）。
- 附有伤害步骤早见表（PDF）；伤害步骤编号 ③-ⅴ 战斗破坏确定、④ 伤害计算后、⑤ 战斗结果解决时、⑥ 伤害步骤结束时。
- 有些条目写明「当時調整中」并给出后来的回答，引用时照抄。
- 获取：`scripts/kanpa.py fetch`（note 公开接口，返回 HTML 正文）。

## Yugipedia（英文 wiki）

- 勘误记录：`https://yugipedia.com/wiki/Card_Errata:<英文卡名，空格换下划线>`，`?action=raw` 取源码；「== Japanese ==」一节按收录的卡包列出历次日文卡文和增删（`<ins>`、`<del>`）。
- 适合：wiki 没有 2011 年存档时，确认“当时的卡文”。例：《未来融合》DT11-JP041 的卡文。

## OCG 规则资料站

- <https://ocg-rule.readthedocs.io/zh-cn/latest/>（现代规则的中文整理）。
- 只在“这条规则从来没变过”时引用，写明是现代资料。例：攻守计算的顺序、计算时出现小数按四舍五入（`c03/攻守计算.html#id8`）。

## 卡库（cards.cdb）

- 1103 卡池的四语卡库（zh-CN / ja-JP / en-US / ko-KR）是卡名的唯一来源；不要凭印象写译名。
- 日版客户端还有异画库（如 `sub-pics.cdb`）：卡号不在 1103 卡库时，先查是不是异画卡号（`datas.alias` 指向本卡）。
